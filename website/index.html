Un escritorio para tus agentes de línea de comandos

Panel local para despachar agentes de línea de comandos sobre los repos de la máquina y ver gráficamente en qué va cada uno. Cada petición nueva levanta un coordinador — un agente CLI de verdad, no código de servidor — que decide en cuántas sesiones se divide el trabajo y delega por archivo, nunca por red.

Cómo funciona

Cuatro piezas hacen todo el trabajo: un coordinador que delega, dos motores de CLI soportados, aislamiento por worktree para cada tarea de escritura, y un scheduler que impone el cupo antes de que cualquier proceso nazca.

Σ

Coordinador de verdad

Un agente CLI real decide en cuántas sesiones paralelas se divide el trabajo y delega escribiendo un archivo — no hay lógica de servidor decidiendo por él.

⌥

Dos motores

claude (Claude Code) y agy (Antigravity CLI), cada uno con sus propios hooks — la tarjeta nunca adivina el estado leyendo la terminal.

⑂

Aislado por worktree

Una tarea en modo escritura corre en su propio git worktree, fuera del repo, nunca mutando el checkout compartido.

▣

Cupo antes que nada

El scheduler impone el tope de paralelismo global y por conversación antes de cualquier spawn — un coordinador sólo puede pedir, nunca lanzar.

El movimiento significa algo

El estado de un agente se lee por color y por movimiento, a propósito: lo que se mueve está avanzando, lo que está quieto está detenido. Estos cuatro robots son el mismo componente que dibuja cada tarjeta real, en vivo, ahora mismo:

Instalar y correr

Sin paso de compilación. Windows, con claude y/o agy disponibles en el PATH.

# npm bloquea los scripts de postinstalación de electron por defecto
npm install
node node_modules/electron/install.js
npm start
