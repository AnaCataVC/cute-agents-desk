Proyecto Experimental en Fase Alfa (v0.1.0)

Cute Agents Desk es una herramienta de ingeniería y banco de pruebas de arquitectura en desarrollo activo. Actualmente no se distribuyen binarios cerrados autoinstalables: se ejecuta localmente desde el código fuente sobre Windows 10/11 con Node.js y los CLIs instalados. Las capas IPC, hooks de motor y el formato del buzón de coordinación están sujetos a mejoras continuas.

🛠️ Prototipo Funcional

Harness local para explorar concurrencia multi-agente, gobernanza de cuotas de tokens y aislamiento estricto de repositorios.

💻 Ejecución desde Fuentes

No requiere empaquetado cerrado: clonas el repositorio, configuras tus cuentas de GitHub locales y corres con Electron puro.

🔄 Interfaces en Evolución

Los contratos de telemetría de herramientas y las políticas de lectura pueden cambiar a medida que los CLIs se actualizan.

💬 Retroalimentación

Te invitamos a probar el harness, validar las suites de pruebas y compartir observaciones en los Issues de GitHub.

Capacidades del Runtime

Diseñado para el Caos de Múltiples Agentes Concurrentes

Cuatro pilares de ingeniería eliminan la fricción, colisiones y fugas de contexto al ejecutar múltiples sesiones de agentes sobre tus repositorios de desarrollo.

Σ

Coordinador Autónomo CLI

Un agente CLI real decide en cuántas sesiones paralelas se divide el trabajo y delega escribiendo en colas JSON vigiladas en disco. No hay lógica de servidor tomando decisiones por él.

⑂

Aislamiento por Git Worktrees

Cada tarea en modo escritura corre en su propio git worktree efímero con rama dedicada (<engine>/<task>-<id>), manteniendo tu checkout principal 100% limpio.

⌥

Doble Motor Nativo

Soporte integrado para claude (Claude Code) y agy (Antigravity CLI), con captura de ciclo de vida mediante hooks de proceso sin depender de escaneos frágiles de texto.

👥

Gobernanza Multicuenta GitHub

Mapeo estricto de repositorios locales vinculados a perfiles (accounts.json). Previene autoría cruzada o fugas entre proyectos personales y laborales en la misma máquina.

▣

Control de Cuotas & Paralelismo

El scheduler impone topes de concurrencia antes de cualquier spawn. Telemetría directa de suscripción con advertencias preventivas al 80% y corte automático al 100% de la cuota.

🚀

Pipeline Seguro de PRs

Al completar una tarea, el sistema realiza commit con las credenciales exactas de la cuenta activa, hace push seguro y crea automáticamente un Pull Request en borrador (gh pr create --draft).

Especificación Técnica

Dos Motores CLI, Dos Filosofías de Hooks

Claude Code y Antigravity CLI no comparten mecanismo de integración. Cute Agents Desk implementa adaptadores especializados para normalizar la telemetría en un modelo común:

Propiedad Claude Code (claude) Antigravity CLI (agy)
Configuración de hooks Parámetro --settings <ruta> arbitraria Fija en <cwd>/.agents/hooks.json
Directorio de trabajo (CWD) El repositorio (o su worktree en escritura) Directorio del agente en el harness; repo entra por --add-dir
Formato de payload snake_case (tool_name, tool_input) camelCase (toolCall.name, stepIdx)
Aislamiento por worktree Soportado directamente como CWD Soportado mediante --add-dir <worktree>
Modo lectura Denegación de tools (Edit|Write|NotebookEdit) Lista blanca estricta de tools confirmadas de lectura
Telemetría de cuotas Línea de estado en vivo + claude -p /usage Lectura de suscripción mediante agy -p /usage

Instalación y Verificación Local

Sin empaquetados pesados ni pasos de compilación complejos. Windows 10 u 11 con Node.js 20+ y al menos uno de los motores CLI disponibles en el PATH del sistema.

PowerShell — cute-agents-desk
# 1. Clonar el repositorio localmente
git clone https://github.com/AnaCataVC/cute-agents-desk.git
cd cute-agents-desk

# 2. Instalar dependencias e inicializar binario de Electron
npm install
node node_modules/electron/install.js

# 3. Validar el entorno con la suite automatizada (22 scripts herméticos)
npm test

# 4. Iniciar el panel de control de escritorio
npm start
✓ Windows 10 u 11 (64-bit)
✓ Node.js 20+ y npm
✓ Git configurado en el PATH
✓ GitHub CLI (gh auth status)
✓ Motor claude o agy en el PATH
